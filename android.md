## Android Guide

### Setup
1. You just need to own an android

### INSTALL
1. Download the .apk from the [releases[1]](https://github.com/JeremiahGironGD/FFLL/releases) page
2. Open the .apk file
3. Click on allow
4. If an alert pops up saying "This app is not verified" click on "Install anyway"

### Updating
1. Download the new .apk from the [releases[1]](https://github.com/JeremiahGironGD/FFLL/releases) page
2. Repeat the steps from install
