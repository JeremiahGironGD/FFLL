# iOS guide

## Setup

1. You need to have [AltStore](https://altstore.io/) installed on your phone 
2. You need AltServer on your computer
3. If you have both apps then download the .ipa from the [releases[1]](https://github.com/JeremiahGironGD/FFLL/releases) page
4. When the ipa is downloaded login to AltStore
5. Go to the "My Apps" tab at the bottom
6. Click the + button in the top left corner
7. In the File Explorer, select the .ipa file you downloaded

## Updating

The app should update automatically unless an update to the app loader is changed. When it is changed, you will return to the [releases[1]](https://github.com/JeremiahGironGD/FFLL/releases) page and download the new version of the app.
When you click the + button in altstore and select the new ipa file AltStore will update the app for you.

## SideStore
1. If you have SideStore installed just do the same as the AltStore steps, but you don't need a computer
